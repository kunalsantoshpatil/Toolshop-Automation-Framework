# Practice Software Testing API – Postman Automation

## 📌 Project Overview

This project contains an automated API testing collection created using **Postman** for the **Practice Software Testing** application.

The project demonstrates practical API testing concepts including:

- REST API testing
- GET, POST, PUT, PATCH and DELETE requests
- Request and response validation
- HTTP status-code validation
- Bearer token authentication
- Environment variables
- Dynamic test data
- API chaining
- Response data extraction
- Automated assertions using JavaScript
- Collection Runner execution
